Приставка · Корень · Суффикс · Окончание

8 min
Teacher: Every Russian word (roughly) breaks into up to four building blocks. Not every word has all four — but every word has a root. Introduce the four colours; Mike will see them used consistently for the rest of the lesson.

The Four Building Blocks

приста́вка
prefix
goes before the root
ко́рень
root
carries the core meaning
су́ффикс
suffix
shapes word type
оконча́ние
ending
shows grammar (gender, case…)
The one rule that matters most: the ко́рень (root) is the part that stays constant across the whole family and carries the real meaning. Everything else — prefix, suffix, ending — just adjusts that meaning or fits it into a sentence.

Разбира́ем сло́во по соста́ву — Taking Words Apart

22 min
Teacher: Go family by family. For each word, first let Mike guess where the breaks are, then reveal the card. The root stays the same colour and (mostly) the same letters across all three words in a family — that repetition is the whole point.
ненави́деть — to hate
ненавидеть
prefixrootsuffixending
nee-na-VEE-deet' — не- ("not") + -вид- (an old root tied to "seeing/regarding") + verb suffix/ending
не́нависть — hatred
ненависть
prefixrootsuffix (∅ ending)
NYE-na-vees't' — same не- and root, now with the noun-forming suffix -ть and a zero ending
ненави́стный — hateful
ненавистный
prefixrootsuffixending
nee-na-VEEST-nyy — the adjective suffix -н- is the same one from краси́вый-type words
See the pattern? The root -навид-/-навис- barely changes — same letters, same core meaning, three grammatical jobs. This is why word families are worth learning as a set.
обеща́ть — to promise
обещать
prefixrootsuffixending
a-bee-SHCHAT' — об- ("around/about") + an old root related to "speaking, declaring"
обеща́ние — a promise
обещание
prefixrootsuffixending
a-bee-SHCHA-nee-ye — the very common noun suffix -ани-/-ени- you've now seen in движение, явление…
обе́щанный — promised
обещанный
prefixrootsuffixending
a-BYE-shchan-nyy — double -нн- is the signature of a "passive participle" (an adjective made from a verb)
воспи́тывать — to raise / bring up
воспитывать
prefixrootsuffixending
vas-PEE-ty-vat' — вос- ("up/completion") + root related to "пита́ть" (to feed/nourish)
воспита́ние — upbringing
воспитание
prefixrootsuffixending
vas-pee-TA-nee-ye — same -ани-/-ени- noun suffix again
воспи́танный — well-mannered
воспитанный
prefixrootsuffixending
vas-PEE-tan-nyy — the same -нн- passive-participle signature as обе́щанный
Two families, same skeleton: обеща́ние and воспита́ние; обе́щанный and воспи́танный — different roots, identical suffix/ending pattern. Once Mike recognises the pattern -ани/-ени-+-е (noun) and -нн-+-ый (participle-adjective), he can build them onto almost any verb.
люби́ть — to love (no prefix here!)
любить
rootsuffixending
lyu-BEET' — a good example of a word with no prefix at all: root + suffix + ending is enough
любо́вь — love
любовь
rootsuffix (∅ ending)
lyu-BOF' — same root люб-, zero ending (typical for feminine nouns ending in a soft consonant)
люби́мый — favourite / beloved
любимый
rootsuffixending
lyu-BEE-myy — suffix -им- makes a "present passive participle": literally "being loved"

Часто встреча́ющиеся кирпи́чики — Common Prefixes & Suffixes

10 min
Teacher: These pieces reappear everywhere. Mike doesn't need to memorise a list — just recognise them on sight from now on.
Prefixes — приста́вки
не-not / un-
об-around / about
вос-/воз-up / arising
у-away / completion
на-onto / accumulation
меж-between
Suffixes — су́ффиксы
-ани-/-ени-action → noun
-нн-/-анн-verb → passive adj.
-н-noun → adjective
-остьadj. → abstract noun
-им-/-ем-"able to be ___ed"
-ива-/-ыва-repeated action
Try it yourself: возни́кнуть (to arise) → prefix воз- ("upward/arising," matches вос-/воз- above) + root -ник- + suffix -ну- + ending -ть. Междунаро́дный (international) → prefix меж- ("between") + root -народ- ("nation" — you found this one yourself!) + suffix -н- + ending -ый.
✏️

Твоя́ о́чередь — Now You Try

5 min
Teacher: Give Mike each word with no colours. He marks where he thinks the breaks fall, then check together.
уста́вший
Where's the root? (Hint: same root as уста́ть/уста́лость from two weeks ago.) → у- + -ста- + -вш- + -ий
интере́сный
This one has no prefix — just root + suffix + ending. → интерес- (root, a borrowed word) + -н- + -ый
почтальо́н
Root по́чт(а) + a borrowed French suffix -альо́н, zero ending. A nice example of a "loanword" suffix.

Мини́-диало́г

3 min
Оле́кс:
Майк, из чего́ состои́т сло́во «люби́мый»?
Mayk, eez chee-VOH sas-ta-EET SLOH-va lyu-BEE-myy?
Mike, what is the word "любимый" made of?
Майк:
Ко́рень «люб», су́ффикс «им», оконча́ние «ый».
KOH-reen' lyub, SOO-feeks eem, a-kan-CHA-nee-ye yyy.
The root is "люб", the suffix is "им", the ending is "ый".
Оле́кс:
Отли́чно! Тепе́рь вы понима́ете структу́ру сло́ва.
At-LEECH-nuh! Tee-PYER' vy pa-nee-MA-ye-tye stroo-KTOO-roo SLOH-va.
Excellent! Now you understand the structure of the word.
